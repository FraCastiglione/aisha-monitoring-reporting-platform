## Follow-up repairs and verification

The follow-up below supersedes the earlier pending verification statuses. These changes were verified locally before the user authorised publication on 3 October 2026.

- Replaced the three blocking native confirmation prompts with accessible in-page dialogs. Task and WP Cancel preserve the contribution; Confirm clears it and declares no work. Communication Cancel preserves the form; Confirm imports the report. Initial focus is on Cancel and the dialog has a labelled explanation.
- Communication review rejects malformed shared event codes. A valid zero-participant event, zero social posts and unknown reach proceed to review. Importing two articles with the same note restores it once; source tests also preserve two distinct notes.
- Manually exercised WP leadership creation, task assessment, completion and no-work transitions. Bulk extra selection added two Tasks and one WP as drafts. Extra WP save, completion and removal passed.
- Verified KPI close-without-saving, required reference, decimal value saving/editing and removal. All 114 definitions pass valid-input and invalid-value/evidence/code tests, including counts and required calculation pairs. Required activity scope is now enforced during import and coordinator intake, matching the editor.
- Selective whole-report import included only the chosen Task. A subsequent KPI-only import for the same timeline retained that Task. An individual T1.1 PDF was rejected when aimed at T9.1; importing it into T1.1 retained the existing KPI.
- Draft WP PDF text extraction and rendered inspection confirm “Leadership update draft — still to finish”; embedded data is preserved exactly. Communication draft PDF preparation is now available even before the form is finished.
- Text boundary tests accept 100,000 characters and reject 100,001. Aggregate backup checks use UTF-8 bytes. Oversize review now displays an error rather than failing silently. Contributor-only drafts saved before timeline selection can now be reopened through report import; this edge path was checked in the source harness.
- Desktop and 390px mobile Gantt/KPI screenshots were inspected. The enlarged Gantt popup was genuinely clipped by its transformed container; centring now avoids that transform and placement uses the actual popup size. Rechecked at 1280px: popup right edge 1268px, within the viewport. Mobile pages had no document-wide overflow. Calendar review drafts and official deadlines appeared on the first and last day respectively.
- Private synthetic intake pilot processed a valid confirmed report, rejected a malformed partner report and preserved privacy in the dashboard candidate. Private reviewer parsing now rejects malformed/repeated claims, returns unchecked acceptance to pending and clears stale summary text after an invalid file.
- Evidence acceptance resets when the claim changes. New or changed related claims also reset overlap approval while retaining unchanged evidence checks. Regression verifies both cases and unchanged checked claims.
- Preview asset versions were refreshed to prevent old HTML/assets mixing during reloads.
