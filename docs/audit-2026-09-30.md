## Operating limits and follow-up

- GitHub Pages is a static public site. Browser Save/Restore uses local storage for the selected partner and report type on that device; the browser can clear it. Downloaded draft PDF and JSON files are the portable backups. There is no server account, shared draft store or automatic submission.
- The public message board is read-only. Coordination messages are published by updating `dashboard-data.json` and redeploying; the seed has no invented announcements.
- KPI values in partner files are self-reported claims. The coordinator must verify evidence, resolve duplicate people or shared activities, and review percentage bases before publishing dashboard actuals. A Nextcloud confirmation in the report records the partner's statement; the site cannot verify Nextcloud contents.
- Voluntary contributions remain separate from formal Task coverage until the coordinator reviews and allocates them in the intake workflow. This prevents a new, unlisted contribution from silently changing the Agreement assignment baseline.
