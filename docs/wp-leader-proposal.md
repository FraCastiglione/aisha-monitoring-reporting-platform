# Work Package leader reporting — implemented preview

Partners who lead an active Work Package in the signed Grant Agreement see a separate leadership section in the same partner report. For IF.E this includes WP1, WP9 and WP10. The section is available only in months when the Work Package is active.

The leader can record overall progress, coordination and integration work, difficulties, next priorities, and requested coordinator support. For each active Task in the Work Package, including Tasks led by other partners, the leader may select On track, At risk, Delayed, Completed, or Update unavailable, with optional progress, blocker and next-action notes. Agreement objectives, Task descriptions, Task leaders and stated outcomes appear alongside these fields. The leader may declare no Work Package work, which clears the answers.

These are leader assessments, distinct from the partner's own Task contributions. They do not certify that another partner submitted a report or completed a deliverable. The updates are saved in whole-report drafts, appear in the review screen and generated PDF/JSON pair, and are checked by the private coordinator review tool. A leadership-only report is valid. The public dashboard receives no automatic update.
